# O olfacto, o gusto e o tacto

Apuntes interactivos autónomos a partir de dos páginas de Ciencias da Natureza en gallego. Incluye mapa mental, cuatro niveles de estudio, comparación, práctica, examen, tarjetas de repaso, tres idiomas, impresión y exportación/importación del progreso.

Abrir `index.html` en un navegador; funciona sin conexión.
